# 最低可投稿闭环

当前状态：**尚不支持投稿**。论文结构已形成，但核心结论仍缺少训练结果和充分实验。

## Gate A：现象成立

- [x] 至少 50 条基线示范完成完整时序干预网格（2450 条轨迹）。
- [x] 只在稳定基线成功子集上进行配对分析（35/50 条）。
- [x] 报告左右臂、阶段、延迟三个因素及有效样本数。
- [ ] 已报告 Wilson 95% 置信区间；仍需在预注册条件上完成配对检验与多重比较校正。
- [ ] 对非单调区间检查接触状态，排除仿真异常和控制器数值问题。

通过标准：能够可靠回答“动作不丢失时，相对时序是否仍会改变物理执行结果”。

## Gate B：方法带来学习收益

- [x] 已实现稳定成功反事实的 robomimic 风格导出，并通过格式与训练冒烟测试。
- [x] 已建立不复制4 GB原始数据的图像 HDF5 外部链接子集，并跑通三视角 ResNet-18+BC-RNN 单步训练。
- [x] 已实现近边界失败标签和独立导出；困难失败不进入行为克隆动作监督。
- [ ] 完成 Source Only、Random Delay、Positive Only、完整方法四组核心对比。
- [ ] 至少覆盖 5/10/25 条源示范和 3 个随机种子。
- [ ] 所有方法保持相同成功动作数量、候选仿真预算和训练更新次数。

诊断记录：N=5、seed=1 的 Source Only 与 Positive Only 在20个未见初始状态上均为0/20成功，存在地板效应；该结果不计作核心对比。平均最小任务距离为0.3515 vs. 0.3401，尚无稳定配对优势。

追加诊断：N=25 轻量状态 BC-RNN 在20个测试状态及5个训练状态上均为0%成功。512维 LSTM、200 epoch 以及加入完整关节状态后，训练状态复现仍为0/5；因此正式基线必须切换为官方三视角视觉 BC-RNN 或同等级序列策略。

通过标准：完整方法在主要少样本设置中稳定优于 Source Only，并优于等预算 Random Delay 或 Positive Only；优势不能只来自更多数据。

## Gate C：创新点不可被简单替代

- [ ] 冻结窗口 vs. 动作完整后缀延迟。
- [ ] 随机选择反事实 vs. 敏感性筛选。
- [ ] 仅成功反事实 vs. 成功样本加困难失败监督。
- [ ] 瞬时成功标签 vs. 稳定保持标签。
- [ ] 至少一个轻量策略与一个强策略架构。

通过标准：至少一个关键组件在配对实验中有明确贡献，并与论文声称的创新一致。

## Gate D：结论具有任务广度

- [ ] TwoArmThreading 完整实验。
- [ ] 增加至少一个协同机制不同的任务，例如 handover、transport 或 assembly。
- [ ] 在未见初始状态或物体姿态上评估。
- [ ] 统计并展示主要失败类型。

通过标准：结论不依赖单一穿线任务的特殊接触几何。

## Gate E：投稿增强项

- [ ] 少量实机示范或仿真到实机验证。
- [ ] 仿真敏感阶段与实机失败阶段的一致性分析。
- [ ] 与 Ego 视频/跨具身重定向轨迹连接。
- [ ] 开源脚本、配置、种子、数据划分和可复现命令。

实机不是所有仿真论文的绝对前提，但如果只做一个仿真任务且没有实机，证据通常不够。若没有实机，应以更多任务、更完整基线和更强统计补偿。
